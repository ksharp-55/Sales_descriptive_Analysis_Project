# Sales_descriptive_Analysis_Project
Published the Sales Descriptive Analysis Project on GitHub, including cleaned datasets, Python scripts, analysis notebooks, visualizations, and documentation. This repository provides a reproducible workflow form data collection to insights, showcasing my skills in data analysis, visualization, and project documentation


## Project Overview
This project analyzes 5 years of sales data to uncover key trends, top-performing products, and regional performance insights. The goal is to provide actionable insights to support business decision-making


## Objective 
-Analyze historical sales data
-Identify top-performing products and regional trends
-Create visualizations and document insights for stakeholders


## Key Results
-Complete set of descriptive sales metrics calculated
-Trends and patterns identified across products and regions
-visualizations created for clear communcation of insights
